05 / QUICK START

三分钟，开始你的第一个实验。

一个 HTML 文件，一个完整的感知、决策与行动入门流程。

01 · 规划一条最短路径

  1. 打开「自主导航」，保持仓储通道与 A* 默认设置。
  2. 点击「开始运行」，观察路径与探索节点。
  3. 选择 BFS 重跑，对比规划时间与路径长度。
  4. 用障碍物工具拖动编辑地图；用起点、目标工具改变任务。

02 · 训练一个导航策略

  1. 导航地图会自动共享到「强化学习」。
  2. 点击「开始训练」，观察奖励移动平均与成功率。
  3. 点击「评估策略」，检查无探索时能否到达目标。
  4. 导出策略 JSON；在导航页面「载入环境 / 策略」可以恢复。

03 · 控制机械臂

  1. 点击画布，机械臂将移动到可达目标。
  2. 点击「自动抓取并放置」，观察接近、抓取、转移和释放。
  3. 调整臂长或肘部方向，比较不同的逆运动学解。
  4. 手动抓取：点击物体 → 闭合夹爪 → 点击放置区 → 松开夹爪。

实验边界与可复现性

导航使用已知完整地图与理想定位，四向移动、单位步长；没有相机、SLAM 或动力学仿真。Q-learning 是真实表格更新，固定地图、种子和参数可复现完整训练。

种子在「自主导航」设置，修改后点击「重建地图」生效。每次训练重新初始化随机数与 Q 表。机械臂为二维解析运动学，不连接硬件。

无需联网、服务器或第三方库。建议使用近期 Chrome、Edge、Safari 或 Firefox。所有实验都在当前设备运行，轻量训练会分批执行。

快捷键：在自主导航页面用方向键手动移动；空格开始 / 暂停自动导航。编辑输入框时不拦截按键。环境与策略支持文件导入导出，实验记录会尽力自动保存。
