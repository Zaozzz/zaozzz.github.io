Four steps to get started

  1. Download and unzip the folder

    You will get a PersonalOS-Starter folder. Open PersonalOS.html to use the blank dashboard immediately. No runtime installation is needed.

  2. Open the folder in an AI editor

    Install Trae, Cursor, or another AI editor that can read and write local files. Open the entire starter folder, rather than just the HTML file.

    Trae ↗ · Cursor ↗

  3. Give the AI the prompt below

    Ask the AI to read the included instructions, collect the essential information, and update data/personal-os.json and notes/. Missing facts stay blank. Start with a few important tasks.

  4. Import your data and start

    Open PersonalOS.html, click Import (导入), and select the JSON updated by the AI. Review it before confirming. The dashboard interface is Chinese, and a fictional example is included.

Use it day to day

  1. Plan the day

    Choose a few important tasks, write the next step, and keep buffer and rest time in the schedule.

  2. Record what happened

    Update progress and record actual minutes, observations, or expenses. Unknown numbers can stay blank. Compare options in Decisions and confirm the final choice yourself.

  3. Export before asking the AI to update

    Export the latest JSON into the workspace. Back up the old file, then save the export as data/personal-os.json. Ask the AI to compare, back up, and update it; import the revised file back into the dashboard.

Understand the two data copies

Browser changes are stored in that browser, not automatically written into the JSON file. Export before clearing browser data, moving the HTML file, or changing devices.

The dashboard runs offline and contains no AI model. Whether your editor sends content to the cloud depends on the product, model, and settings you choose.

Calendar exports must be imported manually. Reminder behavior depends on your calendar permissions and settings. The HTML app does not run background reminders after closing.

Example people and records are fictional. Start with blank data for real use; plans, actuals, and final decisions remain separate.

What is included?

PersonalOS.html, blank JSON, a fictional example, setup prompts, AI workspace instructions, profile and planning templates, and an optional validation tool.
