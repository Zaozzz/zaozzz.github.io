从对话到工作台

01

说明要处理的事

选模型，按需附带任务、日程或基本资料。发送前可以查看完整内容。

02

核对具体修改

展开查看标题、日期、用时和下一步。确认前，工作台不会被 AI 修改。

03

在工作台继续操作

应用后即时更新；也可以直接编辑，或点任务上的“讨论”带回左侧。

安装后，四步开始

  1. 拖入应用程序

    打开 DMG，把 PersonalOS Beta.app 拖入应用程序。ZIP 版本解压后也可以安装。

  2. 先试本机演示

    首次是空白工作区。无需密钥即可体验建议与工作台的联动。本机演示使用固定规则，不是大模型。

  3. 配置自己的 API

    打开“模型设置”，核对 API 地址和模型名，点“填写密钥”保存到系统钥匙串，再测试连接。密钥不要粘贴进对话。

  4. 发送、核对、应用

    按需勾选发送范围。计划与草稿建议经本人核对后写入。右侧可以直接编辑任务、日程、记录、决策、社交媒体、健康与财务。

若 macOS 提示未验证的开发者，请先确认下载来源，再由设备使用者按“系统设置 → 隐私与安全性”的官方流程核验。无需关闭系统安全保护。正式面向普通用户分发，仍需维护者提供 Developer ID 并完成公证。

社交媒体、健康与财务

01

社交媒体

管理各平台草稿与发布计划，复制文案后自己发布。AI 可以提出草稿建议，核对后保存；不会代发。

02

健康

记录睡眠、步数、身体感受与健康活动。近七天统计注明有效填写天数，未知数据不补零。

03

财务

记录收入、支出、分类和每月预算；按所选月份汇总并导出 CSV。预算与实际分开，账面净额不代表账户余额。

资料保存在你的 Mac

本机加密与钥匙串

工作区、对话与配置使用 AES-256-GCM 加密。API 密钥独立保存在钥匙串，并绑定对应 API 地址。已有 API 密钥与常见密钥格式误入发送内容时会被拦截，但这不等于能识别所有敏感信息。

发送范围可检查

默认不附带工作区资料。发送时可主动选择社交草稿、近七天健康数值、所选月财务汇总等范围，不含私人备注与账单明细。当前消息与最近十二条对话也会发送；历史对话可能含先前分享的信息，需隔离时请新建对话。

修改有范围，也有副本

AI 只能提出计划、待比较方案和社交草稿，不能代填实际健康或交易记录、标记完成、代发内容或替本人确认决策。不能执行脚本、读任意文件夹或删除记录。修改前保留最多三十份加密副本；系统锁定、睡眠或十分钟无操作后锁定工作区。

无 ZAOZ 后台监控

第一版不含遥测、广告、后台监控或自动同步。JSON 与对话导出是明文，需要自行妥善保存；换设备前应主动导出。加密文件依赖原设备钥匙串，不能只复制密文当作跨设备备份。

没有系统级后台提醒。日程可导出 .ics，手动导入日历后核对时区和提醒权限。离线保护无法抵御已解锁设备上的恶意软件、截图或主动导出的明文泄露。
