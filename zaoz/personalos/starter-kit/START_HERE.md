# 从这里开始

这个文件夹就是一个简易的 PersonalOS 工作区。网页已经做好，可以直接使用；AI 编辑器用来帮助你整理资料和计划。

## 先打开看看

1. 解压整个基础包，不要直接在压缩包里运行。
2. 双击 `PersonalOS.html`，用 Chrome、Edge、Safari 等较新的浏览器打开。
3. 初始资料为空。可以新增任务，也可以点击“使用示例”体验虚构人物的资料。
4. 正式使用时请在“资料”里选择“新建空白工作区”，不要把示例记录改个姓名就当成自己的历史。

首次使用不需要 Python、Node.js、数据库、注册账户或 API 密钥。浏览器不支持本地保存时，页面会提示；请通过 JSON 导出保留记录。

## 用 Trae 或其他 AI 编辑器搭建

1. 安装你选择的编辑器：[Trae](https://www.trae.cn/) 或 [Cursor](https://cursor.com/download)。其他能读写本地文件的 AI 编辑器也可以。
2. 在编辑器中“打开文件夹”，选择解压得到的 **整个 `PersonalOS-Starter` 文件夹**，不要只打开 HTML。
3. 打开 `PROMPT.md`，把全文复制到 AI 对话中。
4. 回答必要的问题，让 AI 更新 `data/personal-os.json` 和 `notes/`。不要把私密文件夹一起加入工作区。
5. 双击 `PersonalOS.html`，点击“导入”，选择 AI 更新后的 `data/personal-os.json`，核对后确认导入。

普通网页聊天也能帮助写计划，但它不能自动修改你的本地文件；你需要手动保存它给出的 JSON，再导入网页。

## 每天怎么用

- **早上**：看“今天”，选少量重要任务；检查“日程”，保留休息和缓冲。
- **完成后**：手动更新任务状态。实际用时只填真实报告的数字，不知道就留空。
- **需要权衡时**：在“决策”里比较选项；采用方案前，由你亲自确认。
- **晚上或准备让 AI 读取时**：点击“导出”，把 JSON 保存回工作区。先把原 `data/personal-os.json` 复制到 `backups/`，再用最新导出替换它。
- **让 AI 再整理**：说“先读取我最新导出的数据，比较并备份现有版本，再帮我整理明天的计划”。AI 修改 JSON 后，需要再次手动导入网页。

网页中的记录保存在当前浏览器，与文件夹里的 JSON 是两个副本；两者不会自动同步。清理浏览器、换设备或移动网页前，请先导出 JSON。

网页自身离线运行。AI 编辑器是否将工作区内容发往云端，取决于你选择的产品、模型和设置；安装编辑器不等于安装了本地离线模型。
