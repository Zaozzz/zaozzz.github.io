# ZAOZ ATLAS｜组织决策演练工作台

一个可以完整操作、离线运行的组织决策展示：从资源与目标约束，到项目组合比较、资料核对、本人确认、执行跟进和决策记录。

- [打开在线工作台](https://zaozzz.github.io/zaoz/decision-lab/)
- [下载单文件离线版](https://zaozzz.github.io/zaoz/decision-lab/ZAOZ-ATLAS.html)
- [返回 ZAOZ 产品页](https://zaozzz.github.io/zaoz/?lang=zh)

## 体验流程

1. 在“决策总览”了解本轮目标、预算、人力和主动观察。
2. 在“方案推演”切换新品上市、供应受阻、预算收紧三种情境，调整约束和目标权重，或加入压力事件。
3. 在“项目组合”锁定、排除或搜索项目，查看前置依赖。
4. 在“依据与风险”核查资料状态与模型假设。
5. 在“审批与执行”写下选择理由并完成本人确认，再按前置关系推进任务。改变条件或所选方案会使原确认失效。
6. 在“决策记录”导出 JSON 记录或独立 HTML 简报。导入记录后，需要重新审阅并确认。

## 运行与数据

无需安装依赖。可用静态文件服务器打开本目录，也可直接打开 `index.html`，或打开已打包的单文件 `ZAOZ-ATLAS.html`。所有脚本和样式都在本目录内；离线时返回品牌页的链接需要网络。

该原型使用虚构组织“远川设备”、八个虚构项目和六份内置示例资料。没有外部模型调用、账户系统、真实审批、付款、对外通知或业务接入。浏览器本地存储可能受隐私设置限制；使用导出功能可以保存记录。

## 计算口径

- 检查八个项目的全部 255 种非空组合，执行必选、排除、前置依赖、预算、人周、工期与风险约束。
- 目标贡献为项目的增长、韧性与客户体验评分的加权和；未建模协同与重叠，不代表收益或成功概率。
- 风险为按项目预算加权的演练风险分。
- 工期由前置依赖计算最早完工时间；未实现按周的资源均衡调度。
- 资料覆盖度为去重后关联资料中“已核对”的占比。

界面内也提供这些口径，便于理解结果的适用范围。真实使用需要替换数据、验证假设，另行实现身份与权限、服务端持久化和业务集成。

## 文件

`engine.js` 为纯计算模块，可在浏览器及 Node.js 中使用；`atlas.js` 处理交互、状态、导入导出与演练流程；`atlas.css` 提供响应式界面。该展示不要求后端、GPU 或后台计算。
