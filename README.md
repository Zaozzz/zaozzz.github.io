## ZAOZ：个人决策优化与治愈性游戏

**让 AI 分担日常，把心力留给重要的决定，把时间还给快乐的生活。**

ZAOZ 希望面向事务繁忙、需要处理敏感信息并亲自承担关键判断的个人，探索安全、可控的主动 AI：在授权范围内完成日常工作、协助时间规划与提醒、为重要决策准备资料，由本人作出最终决定。同时，探索轻松、有温度、可以自在开始和结束的治愈性游戏体验。
